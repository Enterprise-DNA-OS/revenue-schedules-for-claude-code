# record-period

Record the completed month after evidence review.

Run `npm run revenue -- record-period <YYYY-MM-01> --evidence=<performance-and-reconciliation-evidence> --actor=<accountant> --json`. Read the full result before summarising.

Read the contract evidence and compliance findings first. The accountant decides the treatment. Do not invent approval, recognition evidence, policy or dates. This writes the local review register only; it does not post a journal.

If a name is ambiguous, show the candidates and stop that action. Never guess a record or manufacture evidence.
