# Why the review desk has no front end

Finance teams ask for a month, contract, discrepancy or supporting evidence. A database and an agent can answer those questions and record the accountant's instruction. The weekly routines live in .claude/commands and work with Claude Code, Codex, OpenCode or Cursor.

npm run view renders private read-only HTML. npm run docs produces printable contract assessments, revenue schedules and retention records. brand.json supplies the business name, logo and colours. /new-view adds another SELECT-based report.

A screen offers interactive filtering, mobile capture, drag and drop and a managed permission interface. This base offers none of those. It runs local commands, has no offline sync between devices and does not provide a multi-user approval portal. Enterprise DNA builds the required screens and controls into the owner's version. A shared Postgres database needs reviewed access roles and backups; local PGlite needs device protection and backups.

No financial record is sent, posted or billed by these commands.
